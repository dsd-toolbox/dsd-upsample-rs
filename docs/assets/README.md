# Icon

The dsd-upsample icon (rising steps with an upward arrow), © the dsd-upsample authors, under CC BY 4.0 (`LICENSES/CC-BY-4.0.txt` at the repository root). It is one of the DSD Toolbox icons: a silver disc on a navy rounded square, with the project's motif on an amber panel below it.

| File | Use |
|---|---|
| `icon.svg` | Master drawing, 512 × 512, hand-written SVG |
| `icon-1024.png` … `icon-16.png` | PNG exports at 1024, 512, 256, 128, 64, 32 and 16 px, with transparency |
| `icon.ico` | ICO icon: 256, 128, 64, 48, 32, 24 and 16 px |
| `icon.icns` | ICNS icon: 16 to 1024 px, including the @2x sizes |
| `social-preview.png` | Repository social preview, 1280 × 640 |

Every file here is exported from `icon.svg`. To change the icon, replace all of them together and
keep the file names, so links to them keep working.
